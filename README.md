# yt_kids

A kid-friendly app for watching YouTube videos.

## What this is

`yt_kids` is a simple, safe viewing experience for children. Instead of the
full YouTube interface — with its endless recommendations, comments, search,
and ads for everything under the sun — kids get a small, curated set of
videos and channels that a parent has approved.

## Goals

- **Curated only** — kids can watch what a parent has added, and nothing else.
- **No rabbit holes** — no autoplay into unrelated content, no algorithmic
  recommendations, no related-video sidebar.
- **Simple to use** — large tap targets, pictures instead of text, no login
  required for the child.
- **Parent controls** — an adult adds and removes videos/channels/playlists
  and can set limits on watch time.
